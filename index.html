일본어 단어장

설정

색 조합라이트·다크 모드는 기기 설정을 따라가요.
글자 크기단어, 뜻, 예문, 퀴즈 글자를 키워요.
카드 앞면복습 카드에서 먼저 보여 줄 쪽이에요.
한 번에 볼 카드복습과 카드 공부를 이만큼씩 끊어서 해요.
하루 새 단어오늘의 복습에 새로 섞을 단어 수예요.

‘학습 기록 지우기’는 복습 기록과 오답 노트를 지워요. 즐겨찾기는 그대로 남아요.

복습 간격: ‘모름’은 다음 날, ‘애매’는 지금 간격의 절반 뒤, ‘앎’은 1일 → 3일 → 1주 → 2주 → 1달 → 2달처럼 점점 길게 다시 보여 줘요. 2주 간격에 도달하면 외운 단어(済)로 표시돼요.

N5·N4 표시는 시중 학습 자료를 참고한 대략적인 구분이에요. JLPT는 공식 단어 목록을 공개하지 않아요.

발음은 기기에 설치된 일본어 음성으로 재생돼요. 학습 기록과 설정은 지금 쓰는 기기의 브라우저에만 저장돼요.
